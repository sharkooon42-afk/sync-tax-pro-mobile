# Sync-Tax Pro Mobile

Handy-App zu Sync-Tax Pro (Programm für Synchronsprecher). Diese Seite wird automatisch veröffentlicht;
bitte hier nichts von Hand ändern.

- App öffnen: https://sharkooon42-afk.github.io/sync-tax-pro-mobile/
- Version: 0.3.0
- Die App liest die Datenbank von Sync-Tax Pro nur (Datei von Hand gewählt oder aus dem eigenen Dropbox-App-Ordner)
  und ändert sie nie. Sie lädt nichts von fremden Servern; die einzige Gegenstelle ist Dropbox.
- Enthaltene Fremdbibliothek: sql.js (MIT-Lizenz, `lib/LICENSE-sqljs.txt`).
